JJ DOORS 2026-28 — Door Catalog Extraction
================================================

Source: JJ DOORS_2026-28.pdf (91 pages)
Extracted individual door/product images from all eight requested catalog sections.
Images were taken from the catalog's embedded page images at approximately 2775×1988 source resolution and saved as JPEG quality 100 after necessary cropping to isolate each product.

Category verification:
- Teak Main Door: 139 images; PDF pages 3–27
- Teak Pooja Door: 53 images; PDF pages 28–37
- Teak Architecture Door: 52 images; PDF pages 38–52
- Veneer Door: 54 images; PDF pages 53–66
- Premium Primer Door: 27 images; PDF pages 67–73
- Primer Door: 20 images; PDF pages 74–79
- WPC Door / Door Frame: 37 images; PDF pages 80–89
- UV Coated Doors / Door Frame: 2 images; PDF pages 89

Model/name handling:
- Where a model number/name was visible, it is preserved in the Excel reference and filename.
- Where a contextual/hero image did not expose a model number/name, the filename uses Door_01 or Door_02 and the Excel notes that the model was not identifiable from the catalog image.


Naming update:
Image filenames now follow the catalog model labels, e.g. JJ 1.jpg, JJ 117.jpg, JJ PC01.jpg, JJ WPC01.jpg, V 1501.jpg.
Catalog suffixes such as GANESHI/LAXMI and material annotations are retained where shown.
